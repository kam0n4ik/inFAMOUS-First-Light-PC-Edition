Флаги (все выкл. по умолчанию; выключенный маркер = загрузка статического байта + ветка):
- `SSPC_R8_CP_PROFILE=1` — секции; `=2` — плюс перепись повторов (§5; дорогая, только для анализа);
- `SSPC_R8_CP_PROFILE_WINDOW=<от>:<до>` (с; по умолчанию 70:148 — окно стенда города);
- `SSPC_R8_CP_PROFILE_SAMPLE=N` (32) — каждый N-й пакет PM4 разбирается по классам opcode;
- `SSPC_R8_CP_PROFILE_CSV=1` — `logs\r8_cp_profile.csv`, строка на кадр (сводка: `E:\research\r8\profile\tools\csv_summary.py`);
  в режиме 2 ещё `logs\r8_cp_prep_samples.csv` — каждая 32-я подготовка фронтенда в окне: время, тег, по стадии
  готовность, длина обхода SRT, `flat`, число буферов/текстур/сэмплеров/вершин, «те же регистры», «тот же результат».

Устройство [A]:
- **точные секции** (`R8_CP_PROF(sec)`): RAII на `__rdtsc()`, стек на поток, **собственное** время (вложенная секция
  вычитается из внешней) — секции потока в сумме дают его стену между кадрами; `Other` — непокрытое маркерами.
  thread_local `constinit` счётчики, без блокировок и общих записей на горячем пути;
- **кадр**: поток 1 сдаёт строку на маркере флипа (`R8_CP_PROF_FRAME` в `CommandProcessor`), поток 2 — перед своей
  следующей записью, увидев новый номер кадра; кольцо 8192 кадров на поток + итог прогона;
- **сэмплированные пакеты** (`R8_CP_PROF_PACKET/DECODED` в `CommandProcessor::Step`): у каждого N-го пакета внутри
  секции `Packets` — время `Next`/декода и собственное время исполнения по классу opcode (×N). Сэмпл несёт свои
  `rdtsc` и «лёгкие» маркеры (`BuildDraw`, запись `RegisterFile`, запись журнала регистров), поэтому сырые значения
  завышены (сумма ×1,38 к секции); столбец **share** нормирует классы на секцию `Packets`;
- **классы**: compute (своя работа), sync (поток 1 ждёт поток 2 в drain — по `DrainReason`), wait (очередь/журнал
  полны, чтение поверх записи GPU, `Synchronize`), idle (нечего делать, не входит в «busy»);
- отчёт — раздел `R8 CP profile` в `gpu_native.txt`: окно и весь прогон, мс/кадр, % busy, вызовы/кадр, нс/вызов,
  оценка стоимости маркеров (калибровка пары Enter/Leave на старте потока 1: 63–79 тиков).

Переиспользовано, не продублировано: разбивка фронтенда — `SSPC_GPU_TIMINGS=sample:32`; счётчики
`FrontendStats` (memo, SRT reads), `SrtDiag`, census, `DrainReason`, отчёт ParallelCp — в том же `gpu_native.txt`.
