# Подсказки кнопок игры по устройству ввода (клавиатура/мышь, Xbox, PlayStation)

Ветка `feature/pc-icons`. Исследование и выбор подхода — `PC_INPUT_PROMPTS_PLAN.md` и
`PHASE4_PC_INPUT_UI_RESEARCH.md` §10–§12; здесь описано то, что реализовано.

## Что меняется

Игра рисует каждую подсказку одним иконочным шрифтом: символ PUA в строке и атлас 512×512 RGBA8 в
`lang_<язык>_text.xpps`. Перерисовываются ячейки физических кнопок; виртуальные коды (да/нет, «текущая
кнопка действия», F08E/F08F/F09B/F0B5/F0B6) игра сама сводит к ним. Поэтому меняются все подсказки игры —
статические и составные, на всех языках, — а строки не трогаются.

| Код | DualShock 4 | Клавиатура/мышь (первая привязка действия) | Xbox |
|---|---|---|---|
| F083 / F080 / F081 / F082 | ✕ ○ □ △ | клавиша Cross / Circle / Square / Triangle | A / B / X / Y |
| F084 / F086 | L1 / R1 | клавиша L1 / R1 | LB / RB |
| F085 / F087 | L2 / R2 | L2 / R2 (по умолчанию ПКМ / ЛКМ — значок мыши с выделенной кнопкой) | LT / RT |
| F088 | OPTIONS | Options (по умолчанию Enter) | Menu (☰) |
| F089 | тачпад | TouchPad (Tab) | View (так мост сопоставляет Back → тачпад) |
| F08A | левый стик | блок из 4 клавиш движения (WASD) | стик «L» со стрелками |
| F08B / F08D | L3 / R3 | клавиша L3 / R3 (Shift / СКМ) | LS / RS |
| F08C | правый стик | мышь со стрелками (обзор) | стик «R» со стрелками |
| F090 | крестовина | блок из 4 клавиш DpadUp/Left/Down/Right | крестовина игры |
| F091–F094 | → ↑ ← ↓ | клавиша соответствующего направления | крестовина игры |

Режим PlayStation — оригинальный атлас игры байт в байт. Если действие не привязано ни к одной клавише,
остаётся значок DualShock. Остальные глифы (логотип, второй набор F0E0…, курсоры) не меняются.
Подписи клавиш — латиницей, как на клавиатуре (SPACE, SHIFT, CTRL, ALT, TAB, ENTER, ESC, буквы, цифры,
F1…F12, NUM…), стрелки нарисованы треугольниками. Стиль — как у значков игры: белая фигура, символ вырезан
альфой; шрифт Roboto Condensed Bold (`assets/fonts`), рисует Direct2D/DirectWrite программно
(`src/ui/prompt_icons.*`).

## Как устроено

* `src/ui/prompt_icons.*` — кодек атласа (тайлинг 13: микротайлы 8×8 в порядке Мортона, ряды тайлов
  подряд, изображение снизу вверх), поиск атласа в пакете (id текстуры `29c11c0cac5b95ed` + слова T#
  «8_8_8_8, 512×512, тайлинг 13, pitch 512» + FNV-1a исходных байт; иначе подмена выключается и пишется
  причина), поиск таблицы глифов по записям U+F080/F081, рисование ячеек, сборка атласа.
* `src/runtime/filesystem/content_patch.*` — крючок языковых таблиц: при открытии `lang_*_text.xpps`
  атлас в читаемых байтах заменяется на атлас текущего стиля (файл на диске не меняется), и каждое
  чтение этого диапазона сообщает, по какому адресу гостевой памяти легли байты.
* `src/ui/prompt_service.*` — смена стиля во время игры: проверяет, что по запомненному адресу лежат
  ровно те байты, что были записаны (иначе память освобождена/переиспользована — запись не делается,
  копия забывается), пишет новый атлас и сообщает GPU о записи хоста (`Filesystem::NotifyHostWrite` →
  `GuestWriteNotifier`: собственный Vulkan-бэкенд и мост перезагружают текстуру). Не чаще раза в 300 мс;
  отложенная смена применяется таймером (100 мс).
* `src/input/device_tracker.*` — общий трекер окна игры (`Input::Devices()`), его кормит
  `MenuController::OnEvent` во всех прогонах (автоматических тоже). Клавиша, кнопка мыши, колесо →
  клавиатура сразу; движение мыши — от 40 отсчётов за 100 мс; кнопка геймпада → геймпад сразу; стик
  или курок — от половины хода и не раньше 1,5 с после прошлого переключения. Не переключают: дрожание
  стика, гироскоп/акселерометр (события сенсоров не учитываются), события геймпада при окне в фоне,
  первая секунда после подключения контроллера. Тип: `SDL_GetGamepadType` (PS3/PS4/PS5 → PlayStation,
  Xbox 360/One → Xbox), неизвестный тип — по производителю (Sony 0x054C / Microsoft 0x045E), прочие — Xbox.
* Настройка `[Interface] prompts = auto | playstation | xbox | keyboard` (страница ПК-настроек внутри
  экрана настроек игры): теперь действует и на подсказки игры. Переназначение клавиш (та же страница)
  меняет `KeyboardMouse::LayoutGeneration()` → атлас клавиатуры перерисовывается и записывается заново.

Диагностика: `SSPC_DIAG_PROMPTS=<с>:<стиль>[,…]` — принудительная смена стиля через <с> секунд после
старта (keyboard | xbox | playstation), для автоматических прогонов без контроллера. В логе — строки
`button icons: …`.

## Проверено

* `sspc_settings_tests` : 90/90 (те же проверки входят в `--selftest`, группа Settings; сам `--selftest` не запускался); кодек на случайных данных и на
  настоящем атласе (декодирование → кодирование = те же байты), PlayStation = оригинал, 19 ячеек
  клавиатуры, 14 ячеек Xbox, логотип не тронут, переназначение ✕ Space → F меняет значок, непривязанная
  кнопка — значок DualShock, гистерезис и «тихая» секунда после подключения. Атласы — `prompt_*.png`.
* Игра (копия сохранений, меню паузы с картой): клавиатура → Xbox → PlayStation → клавиатура во время
  игры, собственный Vulkan-бэкенд и бэкенд моста: верхние вкладки (L2/R2 → ПКМ/ЛКМ → LT/RT),
  «✕ Подробности» → SPACE / A, «△ Настройки» → F / Y. Атлас лежит в памяти игры по одному адресу
  всю сессию, перезапись принимается.

## Не проверено / ограничения

* Настоящий контроллер (DS4/DualSense/Xbox) — нет оборудования; переключение по нему проверено только
  самотестами трекера.
* Обучающие подсказки в геймплее (например «Нажмите ✕, чтобы подпрыгнуть») в доступных сценах не
  появлялись; механизм тот же глиф.
* Переназначение кнопок геймпада в SecondSonPC нет: значки Xbox соответствуют фиксированной раскладке
  моста (South=✕, East=○, West=□, North=△, Back=тачпад, Start=Options).
* ~20 строк называют кнопки словами (тачпад, «держите контроллер боком») — не меняются.
* Размер ячеек прежний (50×50 / 58×50): длинные названия клавиш ужимаются.
