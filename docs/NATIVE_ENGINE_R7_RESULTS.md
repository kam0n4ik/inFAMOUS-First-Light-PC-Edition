# R7: Native Engine Expansion — итоги

Ветка `feature/r7-native-core` (локально, без push): R7.0 `3ee73bd` → Core C2/C3 `b45c2dc`, C4 `8afbe3d` → слияния
R7-S `e28753c`, R7-R `e40a8e1`, R7-G `b882919`. База сравнения — пресет стенда **CITY-OPT Phase 6 +
`SSPC_R6_CP_POLL_TRIVIAL`** (`main` `973976b`). Подробности — `NATIVE_ENGINE_R7_{CORE,GBUFFER,SHADOWS,RESOURCES}.md`.

Статусы: `OFFLINE_VERIFIED` — офлайн-сверка с кодом eboot; `GAME_VERIFIED` — сверка в игре (verify/guarded,
0 расхождений); `PERFORMANCE_VERIFIED` — ускорение, подтверждённое чередующимися A/B вне разброса. Проценты
«готовности» по числу функций не приводятся.

## 1. Что теперь исполняется нативно, а что — по цепочке PS4

Всё нативное — **по флагам, по умолчанию выключено**; без флагов игра идёт путём PS4 (eboot → CUE/Gnm → PM4 → CP →
Executor → Vulkan), как в `main`.

|---|---|---|---|---|

`PERFORMANCE_VERIFIED` — ни для чего. Кадр ограничен потоком 1 CP (~30 мс при кадре ~31 мс): нативные участки движка
исполняются на потоках заданий игры и CP не разгружают; C3 меняет транспорт, но не объём работы фронтенда.

Выбросы — по одному прогону в первой паре: `village_all1` (33,04 FPS, CP 21,8 мс) и `harbor_base1` (40,44 FPS,
1 % low 3,31 — одиночный провал кадров). Без первой пары: деревня −0,04, гавань −0,26 FPS. Остальные пары каждой сцены
расходятся в обе стороны на 0,1–0,8 FPS — столько же, сколько прогоны одной конфигурации между собой.

**Итог: все 13 функций R7 разом ни ускорения, ни замедления вне разброса не дают ни в одной из четырёх сцен** —
не PERFORMANCE_VERIFIED; регрессии тоже нет. Это согласуется с §2: нагрузку кадра определяет поток 1 CP и запись
команд, а нативные участки движка работают на потоках заданий игры. Выигрыш от R7 — в том, что эти участки теперь
исполняются собственным кодом с проверкой эквивалентности, а не в FPS.

## 4. Отрицательные результаты и находки

- C3 не быстрее (§2); R4-кэш снимков CUE не реализован (средний снимок 62 байта, экономия — микросекунды);
  дельта dword между снимками 51–55 % — маска изменённых dword сэкономила бы меньше половины decode.
- Падение guarded `0x1a2030` (R7-G): `0x451440` читает 6-й аргумент R9, который трасса не сравнивала — исправлено;
  добавлена автоматическая проверка контрактов (`arg_liveness`, Zydis) для всех 23 записываемых callee.
  **Вывод для всех реконструкций по трассе: арность callee — из его кода, а не из места вызова.**
- Кольцо записанных случаев верификатора (`native_engine_verify.cpp`, 64 на процесс) исчерпывается тестом с массой
  расхождений и роняет чужие проверки (R7-S исправил у себя — инъекция один раз).
- Захват кадра по номеру flip не годится для сравнения изображений: ввод стенда задан по времени.
- Стенд: игровые прогоны получили приоритет над сборками (`E:\research\sspc_game_wait`), сборка, ждущая ≥ 20 мин,
  проходит следующей (`E:\research\sspc_build_wait`).

## 5. Не сделано / дальше

  теневого draw в контракте нет — слой не исполняет теневой draw сам (только сверка команды).
- Потребитель версии ресурсов в CP и мемо ресурсной части стадии — зона `shader/*` (запрещена в R7).
- Игровая проверка редких ветвей `0x1a2030` и видов `0x450460` вне города; A/B `SSPC_R7G_PREFETCH`.
