# Карта шейдеров дыма (SSPC-020)

Все идентификаторы получены из трассировки команд (`SSPC_DIAG_CMD_TRACE`), а не выведены по памяти. Сцена — маршрут
пляжа (`tools\tests\smoke_bench.ps1`, сохранение `logs\performance\p43_ab\snapshot\home`), кадры 1950–1971. Трассы:
`logs\smoke_research\s1_trace\cmd_trace.txt` (f1969–1971), `s3_probe\cmd_trace.txt` (f1950–1955). Разбор —
`tools\smoke_trace.py`.

Идентичность программы: адрес PGM (где лежит код), хеш компилятора из футера (`footer`) и хеш содержимого
(XXH3-128, младшие 64 бита — `content`). Номер pipeline (`p382`) стабилен только в пределах одного маршрута, им для
отбора не пользоваться; адрес и оба хеша совпадали во всех прогонах.

## 2. Данные частиц (двойная буферизация, задержка один кадр)

| Набор | Пул частиц | Список (ключ, индекс) | Заголовок-счётчик | Indirect-аргументы дыма |
|---|---|---|---|---|
| A (чётные кадры) | `0x26f358000` +0xC00000 | `0x26ff58100` +0x100000 | `0x26ff58000` +0x10 | `0x270058100` |
| B (нечётные) | `0x26d558000` +0xC00000 | `0x26e158100` +0x100000 | `0x26e158000` +0x10 | `0x26e258100` |
| Общий ping-pong сортировки | — | `0x271158000` +0x100000 | — | — |

В кадре N compute очереди 1 пишет один набор, draw очереди 0 читают другой (записанный в кадре N−1). Список — пары
u32 (ключ глубины как float, индекс частицы), отсортированные по убыванию ключа (от дальних к ближним).
Заголовок-счётчик не пишет ни один draw/dispatch (его пишет CP/CPU); его читает только сортировка.

## 4. Compute: сортировка частиц (очередь 1)

| Что | Значение |
|---|---|
| CS | `0x2edaa1800`, footer `a16fa93a`, content `80279384190567be` |
| Workgroup | 64×1×1 (одна волна wave64 на PS4); 92–94 группы (по числу частиц) |
| Проходов за кадр | 9, сразу после эмиттеров; параметры прохода (w, max) — 16 байт кольца CPU (`0x24beb…`) |
| Привязки | `#0` заголовок-счётчик (число частиц), `#1` indirect-аргументы дыма (пишет поток 0: `count << 2`), `#2` параметры прохода, `#3` → `#4` списки (ping-pong, по очереди меняются местами) |
| Алгоритм (IR после трансляции) | слияние (merge path): уровень w сливает две отсортированные серии по w/2 в серию w; каждый поток бинарным поиском находит позицию своего элемента и пишет его. Цикл в одном dispatch: слить #3→#4 (w); если 2w ≤ max — слить #4→#3 (2w); w ← 4w; повтор, пока w ≤ max. Нет LDS, нет барьеров, нет волновых операций |
| Параметры | проход 1: (2, 64) — **шесть уровней в одном dispatch** (w = 2, 4, 8, 16, 32, 64; на выходе серии по 64 — 85 разрывов порядка на 5455 частиц); проходы 2–9: (128,128) … (16384,16384) — по одному уровню |
| Зависимости уровней | уровень w читает то, что потоки тех же w элементов записали на w/2: до w = 32 — одна 32-поточная подгруппа NVIDIA, w = 64 — две подгруппы одной группы (на PS4 — одна волна wave64) |

## 6. Найденная ошибка (SSPC-020)

Отсортированный список, который читает draw дыма, — не перестановка: часть индексов повторяется, другие частицы
выпадают. Разбор проб (`SSPC_DIAG_PROBE_CS=2edaa1800:1950:1:0+3+4`, кадр 1950; пары (ключ, индекс), N из
заголовка-счётчика):

| Проход (w, max) | База s5: повторы / нарушения порядка на выходе | По уровню s6: повторы / нарушения |
|---|---:|---:|
| вход (выход эмиттеров) | 0 / 2661 | 0 / 2712 |
| 1 (2, 64) | **464** / 140 | 0 / 85 |
| 2 (128, 128) | 507 / 114 | 0 / 42 |
| 3 (256, 256) | 546 / 106 | 0 / 21 |
| 4 (512, 512) | 582 / 100 | 0 / 10 |
| 5 (1024, 1024) | 630 / 111 | 0 / 5 |
| 6 (2048, 2048) | 659 / 121 | 0 / 2 |
| 7 (4096, 4096) | 732 / 151 | 0 / 1 |
| 8 (8192, 8192) | 795 / 206 | 0 / 0 |
| 9 (16384, 16384) | 795 / 206 | 0 / 0 |

Список, который читает draw (`SSPC_DIAG_PROBE=2edac4000:…:a+1`, N = вершин / 4): база s3 549–956 повторов за кадр
(10–17 % частиц), s4 594–763, s5 738–795; s6, f1 (исправление), k32 — 0 повторов и 0 нарушений порядка в каждом
кадре. Причина и исправление — `docs\PHASE4_SMOKE_PIPELINE.md`, разделы E и G.

## 7. Диагностическое отключение и эксперименты

| Режим | Что делает | Результат |
|---|---|---|
| бисекция pipeline (P4.5) | без p382 | столб дыма исчезает полностью, остальная сцена не меняется |
| `SSPC_DIAG_SKIP_DRAWS=vs:2edac4000,vs:2edadae00` | NO_SMOKE_DRAW: только два draw дыма, симуляция и сортировка работают | реализовано; A/B по FPS не выполнен |
| `SSPC_DIAG_SORT_SPLIT=off` | сортировка как в игре (проход 1 одним dispatch) | мерцание, повторы как в базе |
| по умолчанию | проход 1 — шесть dispatch по уровню | повторов 0, мерцание 0 (пляж s6/f1, деревня визуально) |
| `SSPC_DIAG_SORT_SPLIT=keep:32` | уровни 2–16 одним dispatch, 32 и 64 отдельно | повторов 0: уровни внутри подгруппы безопасны |
| `SSPC_DIAG_SORT_SPLIT=keep:64` | уровни 2–32 одним dispatch, 64 отдельно | прогон прерван, не измерено |
