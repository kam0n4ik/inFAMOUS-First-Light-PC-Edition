# SecondSonPC R6 — Native Render Engine: итоги

Ветка интеграции `feature/r6-core` (worktree `E:\SecondSonPC-native-r5`), без merge в main и без push. В неё слиты
`feature/r6-gbuffer` (R6-G), `feature/r6-shadows` (R6-S) и `feature/r6-cp-optimization` (R6-P). База сравнения —
пресет CITY-OPT Phase 6 (стенд: `SSPC_CP_MODE=native`, `REA_MERGE_RUNS=1`, `CP_ROUND_NODRAIN=1`,
`P411_ASYNC_ACQUIRE=1`, `ASYNC_PIPELINES=1`, `CITY_PERFORMANCE=1`).

Статусы: **ANALYZED** — разобрано по коду; **GENERATED** — код получен переводчиком; **OFFLINE_VERIFIED** — сверка с
кодом eboot вне игры; **GAME_VERIFIED** — двухпутевая сверка в игре, 0 расхождений; **PERFORMANCE_VERIFIED** — прирост
вне разброса в чередующейся серии. Все флаги R6 по умолчанию **выключены**; оригинальные пути не удалены.

### 2.1 `SSPC_R6_CP_POLL_TRIVIAL=1` на других сценах [E]

Серии `r6c_t_<сцена>` (exe `f37b0ed`, пресет стенда, A = пресет, T = + флаг; A,T,T,A,A,T; 90 с, окно 62…88 с —
после маршрута движения 56…60 с). Во всех 18 прогонах ждавших GPU чтений 0 — **и в A**: скрытого фактора города на
этих сценах нет. Error/Critical 0, `env_effective` проверен.

| Сцена | A, FPS по прогонам | T, FPS по прогонам | T − A: FPS / 1 % low / CP мс |
|---|---|---|---|
| пляж | 55,50 / 55,39 / 55,37 | 53,80 / 55,57 / 55,48 | −0,47 / −7,30 / +0,15 |
| гавань | 45,46 / 45,18 / 45,41 | 45,61 / 45,24 / 45,26 | +0,02 / −0,05 / −0,00 |

Прироста T вне города нет (ожидаемо: нечего снимать). Разница 1 % low на пляже и в деревне — по одному кадру-выбросу в
одном прогоне T: это пауза **игрового** потока (между двумя flip игра не отправляет кадр; CP, запись и GPU в эти кадры
в норме). В деревне такая пауза есть во всех прогонах сразу после маршрута (≈61 с): в A 1,1–1,4 с и кончается к
62,2 с — у края окна, в одном T 4,5 с (до 65,6 с); на пляже — 418 мс на 69,3 с в одном T. Механизма, связывающего
флаг (CP перестаёт читать память для всегда истинного опроса) с игровым потоком, нет; исключить по трём прогонам
нельзя — серии `r6c_t2_*` в обратном порядке (§2.2).

## 3. Отрицательные и неподтверждённые результаты

- P5.3 hybrid в городе: −4,4 FPS (CORE §5.4). Не включать.
- Переиспользование снимков CUE: в `r6c_dd1` (без T) +3,57 FPS — целиком скрытый фактор опросов; поверх T (`r6c_dd2`)
