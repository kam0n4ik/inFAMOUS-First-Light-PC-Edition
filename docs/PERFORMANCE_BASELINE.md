## Кэш шейдеров

Статическое предсказание шейдеров по файлам игры: `FirstLightPC.exe --predict-shaders data\static_templates.txt`. Так
же делает SS через `[ShaderCache] predictAll`. Своих шаблонов у FL пока нет; используются шаблоны SS (тот же движок,
те же шейдерные программы материалов).

Насколько шаблоны SS покрывают то, что FL реально использовал в сессии
(`tools\ss_archive\static_shaders\compare_predict.py` против кэша сессии):

| Мера | Покрытие |
|---|---|
| Раскладки (программа + рантайм) | 659 из 740 ≈ 89 % |
| Модули по полному ключу | 266 из 416 ≈ 64 % |

Прогрев 27.10 17:21–17:23, на кэше игры `cache\shaders\CUSA00897\native_own\ca01229ae7bf3517`:
- 536 паков (9,7 ГиБ) прочитаны за 9,2 с;
- 181285 модулей переведены, отказов 196 (первый — `image_sample`, S# не известен при трансляции);
- описано 13179 графических конвейеров, все собраны, отказов 0;
- кэш: `shaders.pack` 1,31 ГБ, `vulkan.bin` (кэш драйвера) 539 МБ.

Время прогрева:

- повторно, когда кэш драйвера NVIDIA уже есть, — 62 с;

`predictAll = true` включён в `FirstLightPC.toml`.

Что ещё нужно:
